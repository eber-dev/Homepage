Mis Proyectos

Etch-a-Sketch

Una pizarra digital interactiva que permite al usuario dibujar sobre una cuadrícula de píxeles dynamicamente mediante eventos del mouse. Creado para dominar la manipulación avanzada del DOM con JavaScript.

Calculator

Una calculadora completamente funcional que realiza operaciones aritméticas básicas. Enfocada en la lógica de programación, el manejo de variables y la captura precisa de eventos de teclado y pantalla.

Wheater-app

El clásico juego de "Tres en línea" desarrollado aplicando los principios de programación orientada a objetos (POO) y el uso de módulos y factories en JavaScript para mantener el código limpio y organizado.

Tic-Tac-Toe

Un sitio web dinámico para un restaurante donde todo el contenido de las pestañas (Inicio, Menú, Contacto) se genera e inyecta dinámicamente mediante JavaScript empleando Webpack. (Enfoque visual).

Restaurant-Page

Aplicación del clima que consume datos en tiempo real desde una API externa. Incluye el manejo de funciones asíncronas (async/await), procesamiento de archivos JSON y renderizado dinámico de la interfaz.

To-Do-List

Una aplicación de gestión de tareas que permite crear, organizar por proyectos, editar y eliminar pendientes. Incluye persistencia de datos a través de localStorage para guardar el progreso del usuario.
